# ВсОШ по ИИ

Задачи к олимпиаде по искусственному интеллекту — трейлами, теория
и проверка к ним: https://conduit-admin.github.io/vsosh-ii/

Страницы читают `data/index.json` и `data/treyly.json` прямо в браузере,
сборки нет. Главная — `index.html`: трейлы, листки теории и архив
проверки; задачи трейлов текстом — `treyl.html`. Содержимое — `data/`:
листки, условия и файлы задач, архив проверки `kontest.zip` и индексы —
собирается скриптом из приватного хранилища и перезаписывается целиком,
руками здесь правится только код: `index.html`, `treyl.html`
и `assets/`. Оформление — «Бумага», как у «Лучезарности» и 11-1.
