# ВсОШ по ИИ

Серии задач к олимпиаде по искусственному интеллекту и проверка к ним:
https://conduit-admin.github.io/vsosh-ii/

Страница читает `data/index.json` прямо в браузере, сборки нет. Содержимое —
`data/`: листки, архив проверки `kontest.zip` и индекс — собирается скриптом
из приватного хранилища и перезаписывается целиком, руками здесь правится
только код: `index.html` и `assets/`. Оформление — «Бумага», как
у «Лучезарности» и 11-1.
